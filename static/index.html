Import files from your phone

Select local .txt, .md or .json files. The content is saved into local LIVING AI memory in chunks. Files up to 2 MB each are supported.

Learn from a public website
Paste one public webpage URL. LIVING AI extracts readable text and saves it to local memory. Redirects, private-network hosts and unsupported file types are blocked; some sites prevent automated access.
Use saved knowledge for training
Export saved memory chunks, including imported files and public webpages, into data/corpus/imported_memory_corpus.txt. Then train your local model from the Training page.
What happens to imported data?
  • TXT and Markdown are imported as text.
  • JSON is validated and pretty-printed while preserving its keys and values.
  • Imported text is stored locally as searchable memory; importing does not automatically retrain the Transformer.
  • For model training, also place permitted TXT/Markdown corpus files in data/corpus/.


Train original model
Put permitted UTF-8 .txt files in data/corpus/. This small character n-gram model is a baseline, not a frontier LLM.
Train your own tiny Transformer from scratch
Starts with random weights and learns next-byte prediction from UTF-8 text. It is a small educational model, not a pretrained assistant. Requires a compatible PyTorch install and can heat/throttle a phone.
